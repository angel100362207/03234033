# 🚀 GOD AI CLI

Crea software nivel Silicon Valley usando IA directamente desde tu terminal.

---

## 🧠 ¿Qué es esto?

**GOD AI CLI** es una herramienta de línea de comandos que te permite acceder a habilidades avanzadas (prompts profesionales) para generar:

- 📱 Apps móviles (nivel NASA)
- 🌐 Aplicaciones web fullstack
- ⚡ Ecosistemas completos tipo Tesla (nivel dios)

Todo listo para usar con cualquier IA como ChatGPT o Claude.

---

## ⚙️ Instalación

Clona el repositorio desde GitHub:

```bash
git clone https://github.com/angel100362207/03234033.git
cd 03234033
npm install
```

---

## 🚀 Uso

### Modo Interactivo

```bash
node index.js
```

Selecciona una opción del menú y el prompt se copiará automáticamente al portapapeles.

### Modo Directo (Línea de comandos)

```bash
node index.js --skill tesla
node index.js --skill mobile
node index.js --skill web
```

### Instalación Global (Opcional)

```bash
npm install -g .
god-ai --skill tesla
```

## 📁 Estructura del proyecto

```
god-ai-cli/
├── index.js                 # CLI principal
├── skills.js               # Exportación de habilidades
├── skills-cli.js           # Lógica del CLI
├── skills-manifest.json    # Registro de habilidades
├── package.json
├── README.md
├── prompts/
│   ├── mobile.txt         # Prompt nivel NASA
│   ├── web.txt            # Prompt fullstack
│   └── tesla.txt          # Prompt nivel dios
```

---

## 🧩 Cómo funciona

1. **Ejecutas el CLI** → `node index.js`
2. **Seleccionas el tipo de software** → Mobile, Web o Tesla
3. **Obtienes un prompt avanzado** → Se copia automáticamente
4. **Lo pegas en tu IA favorita** → ChatGPT, Claude, etc.
5. **Generas software completo automáticamente** → Listo para producción
